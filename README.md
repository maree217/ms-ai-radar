# MS-AI-Radar

A **living catalogue of the latest Microsoft AI & agent solutions on GitHub** — official Microsoft orgs plus high-signal community repos built on the stack. Scanned straight from the GitHub API, filtered for freshness, and re-run weekly so the list never rots.

> Built to solve the problem that hand-curated "awesome" lists drift toward archived and deprecated repos. Here, archived/superseded repos are filtered out automatically and everything carries a freshness badge.

## What it does

- **`scan.py`** — queries the GitHub Search API across Microsoft orgs (`microsoft`, `Azure-Samples`, `Azure`, `microsoft-foundry`, `dotnet`) by keyword **plus** official AI/agent topics across all owners. It drops archived repos and anything not pushed within 18 months, excludes infrastructure repos (e.g. `WALinuxAgent`), flags superseded/deprecated repos, categorises each into 10 buckets, and writes **`catalogue.json`**.
- **`index.html`** — a self-contained, dependency-free page that renders `catalogue.json` with live filtering (category, Microsoft vs community, tier, freshness, language, full-text search) and sorting (stars / newest / recently pushed).
- **`.github/workflows/refresh.yml`** — re-runs the scan every Monday (and on demand), commits the updated `catalogue.json`, and redeploys GitHub Pages.

## Run it locally

```bash
# needs a token: either export GITHUB_TOKEN=... or be logged in with the gh CLI
python3 scan.py            # regenerates catalogue.json
open index.html            # or serve the folder: python3 -m http.server
```

## Publish (GitHub Pages)

1. Push this folder to its own GitHub repo.
2. **Settings → Pages → Source: GitHub Actions.**
3. The `Refresh catalogue` workflow builds + deploys on push, weekly, and via *Run workflow*.

## Tuning

All knobs live at the top of `scan.py`:

| Setting | Default | Effect |
|---|---|---|
| `MS_ORGS` | 5 orgs | which orgs count as "Microsoft" (no star floor) |
| `TOPICS` | 14 topics | discovery topics across all owners |
| `COMMUNITY_MIN_STARS` | 150 | quality bar for non-Microsoft repos — lower = broader |
| `FRESH_MONTHS` | 18 | exclude repos not pushed within this window |
| `DENY_NAMES` / `DENY_DESC` | infra list | excludes non-AI "agent" repos |
